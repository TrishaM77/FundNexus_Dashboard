# Fund Nexus Dashboard
This is a real time data analytics built using python, to monitor call center performance and fundraising metrics.For this project, I used the following packages/libraries:
Pandas
Matplotlib
Plotly
Streamlit

**Note:** The original company data has been removed for privacy. This repository uses sample data.

## Features
1. Contact Rate
2. Conversion Rate
3. Daily Calls vs Target
4. Hot Leads Pending
5. Agent Rankings
6. Donations Collected
7. Disposition Trends
8. Follow-ups Due Today
9. Interactive filters
10. Live updates from Google Sheets

## Technologies Used

1. Python
2. Streamlit
3. Pandas
4. Plotly
5. Matplotlib
6. Google Sheets API

## Installation

1. Clone the repository

```bash
git clone https://github.com/TrishaM77/NGO_Dashboard.git
```

2. Open the project folder

```bash
cd NGO_Dashboard
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application

```bash
streamlit run app.py
```
